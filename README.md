### 🚀 Featured Project
 
**[RaPToR Web]** — From Desktop to Browser
 
A browser-based redesign of a ROS 2 robot teleoperation toolkit, replacing a Python/Tkinter desktop GUI with a React web app. Connects to a custom-built Python/ROS 2 WebSocket bridge for real-time robot control, live sensor monitoring, and session recording.
 
- **Frontend:** [raptor-web](https://github.com/Sunnylin0320/raptor-web) — React
- **Backend:** [RaPToR-Toolkit-react](https://github.com/Sunnylin0320/RaPToR-Toolkit-react) — Python, ROS 2, WebSocket bridge
